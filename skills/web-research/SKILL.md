# Web Research

Use this skill when an answer depends on current or externally verifiable information.

## Workflow
1. Define the question, date cutoff, geography, and required evidence.
2. Search in layers: primary sources first, then reputable secondary sources for context.
3. Open source pages rather than relying on snippets; record publisher, publication/update date, URL, and the exact claim supported.
4. Cross-check material claims with an independent source when feasible.
5. Separate observed facts, calculations, interpretations, and open questions.

## Source discipline
- Prefer laws, filings, official documentation, datasets, original research, and direct statements.
- Use news and commentary to explain context, not to replace primary evidence.
- Note paywalls, missing dates, conflicts, and stale pages.
- Do not manufacture citations or imply a source supports more than it says.

## Output
Use: **Answer**, **Key evidence**, **Caveats**, and **Sources**. Add access dates for time-sensitive claims.
