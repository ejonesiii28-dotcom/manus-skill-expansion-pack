# Document Forge

Use this skill to create documents that are accurate, readable, and inspectable.

## Workflow
1. Confirm audience, purpose, format, length, tone, and required source material.
2. Outline before drafting; keep claims traceable to inputs or cited sources.
3. Generate the document with consistent heading hierarchy, spacing, tables, captions, and page metadata.
4. Render to the requested format and inspect layout, page breaks, overflow, links, encoding, and accessibility.
5. Run a content pass for omissions and a visual pass for presentation quality.
6. Deliver the source plus final artifact when that improves reuse.

## Quality bar
- Prefer plain language and meaningful headings.
- Keep tables narrow and repeat header rows across pages when supported.
- Use alt text or descriptions for meaningful visuals.
- Never invent names, figures, signatures, or approvals.

## Output
State the format, source files, validation performed, and any known rendering limitations.
