# Project Planning

Use this skill to create plans that are actionable without pretending uncertainty is resolved.

## Workflow
1. Restate the outcome, users, constraints, non-goals, success metrics, and deadline if any.
2. Break work into independently verifiable milestones with owners or roles, dependencies, and acceptance criteria.
3. Identify assumptions, risks, unknowns, decision points, and rollback paths.
4. Sequence critical-path work; parallelize only when dependencies permit.
5. Define the first executable slice and a review cadence.
6. Update the plan as evidence changes; keep completed work and open decisions visible.

## Planning rules
- Prefer small increments over a giant batch.
- Distinguish must-have, should-have, and optional scope.
- Put measurable acceptance criteria next to each deliverable.
- Flag decisions that require user or stakeholder approval.

## Output
Use: **Outcome**, **Scope**, **Milestones**, **Dependencies**, **Risks**, **Acceptance criteria**, and **Next actions**.
