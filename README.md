# Manus Skill Expansion Pack

Ten modular skills for stronger, safer work across repositories, research, data, documents, security, APIs, testing, planning, localization, and automation.

## Included skills

| Skill | Purpose |
| --- | --- |
| [repo-maintainer](skills/repo-maintainer/SKILL.md) | Git and GitHub maintenance |
| [web-research](skills/web-research/SKILL.md) | Source-backed research |
| [data-analysis](skills/data-analysis/SKILL.md) | Reproducible data work |
| [document-forge](skills/document-forge/SKILL.md) | Professional documents |
| [security-review](skills/security-review/SKILL.md) | Defensive security review |
| [api-integration](skills/api-integration/SKILL.md) | Reliable API connections |
| [testing-debugging](skills/testing-debugging/SKILL.md) | Debugging and regression prevention |
| [project-planning](skills/project-planning/SKILL.md) | Scope and execution planning |
| [content-localization](skills/content-localization/SKILL.md) | Locale-aware translation |
| [automation-orchestration](skills/automation-orchestration/SKILL.md) | Safe unattended workflows |

## Use

Each skill is a self-contained directory with a required `SKILL.md`. Copy or add the directories to the agent environment that should load them. These skills extend workflows and domain guidance; they do not bypass platform, permission, safety, or subscription controls.
